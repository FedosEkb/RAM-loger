# RAM Logger

Класс предназначен для логирования результатов выполнения тестов непосредственно в оперативную память (ОЗУ). 

## Требования к линковщику (Linker Script)

Для корректной работы класса и определения границ секции лога в памяти, в вашем скрипте линковщика (`.ld`) должны быть объявлены две внешние метки:

* `saveLog` — указывает на начальный адрес секции логирования.
* `__end_of_log_section` — указывает на конечный адрес секции (границу памяти).

### Пример конфигурации памяти (`.ld` файл):
```linker-script
.ram_log (NOLOAD) :
{
    saveLog = .;
    . = . + 0x1000; /* Выделение фиксированного объема под лог */
    __end_of_log_section = .;
} > RAM
```

## Пример использования в коде (C++)

```cpp
#include "StringLog.h"
int main() {
	test_log << "Hi! Let's do some NU test!" << StringLog::endl;
    return 0;
}
```
